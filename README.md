# Part 0 Checkpoints

JavaScript and Node.js practice exercises for managing student records and Gambian transport fares. The repository progresses from JavaScript fundamentals to modular CRUD operations, data transformation, validation, statistics, logging, and an integrated portfolio project.

## Requirements

- Node.js 18 or newer
- No external npm packages are required

## Exercises

### JavaScript fundamentals

`js-fundamentals-quiz.js` demonstrates arrays of Gambian regions, fare objects, `map`, `filter`, `find`, and template literals.

### Student tracker

The `student-tracker` folder stores student records and exposes functions to:

- Create and list students
- Find a student by ID
- Update student details
- Search by name or grade
- Delete a student

### Fare enhancements

`enhancements.js` validates fare input, calculates average and route statistics, finds the cheapest vehicle type, increases fares for a vehicle type, and deletes fares for a route.

### Data transformation

`data-transformation.js` groups fares by vehicle type and route, then calculates minimum, maximum, and average prices for each vehicle type.

### Price updates and logging

`price-update.js` applies a 15% increase to the sample fares, prints the before-and-after tables, and writes the update details to `price-changes.log`.

### Error-handling CRUD

`crud-with-errors.js` demonstrates create, read, update, and delete operations with checks for missing fields, invalid vehicle types, invalid prices, duplicate locations, missing IDs, and unknown routes.

### Portfolio project

`portfolio-project` combines the fare data, CRUD functions, transformations, statistics, and price update workflow into a modular application. Its detailed project notes are in [portfolio-project/README.md](portfolio-project/README.md).

## Running the Examples

Run commands from the repository root:

```bash
node js-fundamentals-quiz.js
node student-tracker/app.js
node enhancements.js
node data-transformation.js
node price-update.js
node crud-with-errors.js
node portfolio-project/app.js
node portfolio-project/price-update.js
```

The two price-update scripts modify their corresponding `price-changes.log` files. Run them only when you want to generate a new log.

## Learning Focus

- JavaScript arrays, objects, and template literals
- `map`, `filter`, `find`, `findIndex`, and `reduce`
- CommonJS modules with `require` and `module.exports`
- CRUD patterns over in-memory arrays
- Input validation and error handling
- Aggregation, grouping, and derived statistics
- File output with Node.js `fs`
